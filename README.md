# Open Bharat (ओपन भारत ब्राउज़र) 🇮🇳

A modern, fast, and reward-driven Indian Web Browser and Portal built with **Jetpack Compose** and **Material Design 3**.

## ✨ Features

- **Tricolor Header & Wallet Display**: Branded Indian tricolor app bar with dynamic live points counter (`👛 XX Pts`).
- **Google Search with Rewards**: Search any web query or enter direct URLs to instantly earn +10 points per search.
- **Integrated In-App Browser (WebView)**: Full navigation controls (Back, Forward, Refresh, Home, Share, Open in Chrome) with SSL security badge and loading indicators.
- **Essential Apps Quick Launcher**:
  - 📺 यूट्यूब (YouTube)
  - ✉️ जीमेल (Gmail)
  - 👥 फेसबुक (Facebook)
  - 📖 विकिपीडिया (Wikipedia)
  - 📰 समाचार (Google News)
  - Plus expandable Indian portals: IRCTC Railway, Cricbuzz, Aaj Tak, Sarkari Result, and Flipkart.
- **Daily Inspiring Shayari (✨ आज की प्रेरणादायक शायरी ✨)**: Curated collection of classic Hindi motivational poems (Harivansh Rai Bachchan, Sohan Lal Dwivedi, Dushyant Kumar, Swami Vivekananda) with "Next Shayari" (+5 Pts bonus), "Copy to Clipboard", and "Share" options.
- **Rewards & Mobile Recharge Center (🎁)**:
  - Mobile Recharge redemptions (₹10, ₹20, ₹50) across Jio, Airtel, Vi, and BSNL.
  - UPI Cash Transfer redemptions (₹25, ₹50).
  - Amazon Shopping Vouchers.
  - Daily Check-in bonus (+25 Pts).
  - Full transactions history and redemption records.
- **Persistent Storage**: Points, daily check-ins, and transaction records persist locally on the device.

## 🛠️ Tech Stack

- **Kotlin** & **Jetpack Compose (M3)**
- **Android WebView** with custom WebChromeClient & WebViewClient
- **SharedPreferences & Kotlin Flow** for reactive state persistence
- **Material 3 Dynamic Theming** with Indian Saffron and India Green accents
